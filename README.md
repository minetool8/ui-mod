# Unified UI (Forge 1.20.1)

Client-side mod: ring hotbar on the left, health/hunger/thirst/temperature bars (vanilla + Legendary Survival Overhaul) on the right,
and hidden potion effect icons. Requires Legendary Survival Overhaul at runtime (not needed to build).

Build: push to GitHub and download the `unifiedui-jar` artifact from the Actions tab,
or run `gradle build` locally with Java 17. The jar is in `build/libs/`.

Config: `config/unifiedui-client.toml`.
