# Unified UI (Forge 1.20.1)

Client-side vanilla-only mod: ring hotbar on the left, health/armor/hunger/air on the right,
and hidden potion effect icons. No other mods required.

Build: push to GitHub and download the `unifiedui-jar` artifact from the Actions tab,
or run `gradle build` locally with Java 17. The jar is in `build/libs/`.

Config: `config/unifiedui-client.toml`.
